# 🔐 Login & Signup Page

A simple and responsive **Login and Signup Web Application** built using **HTML, CSS, Java, JSP, Servlets, JDBC, and MySQL**, developed in **Eclipse IDE**. It features a modern **red gradient glassmorphism** design with a clean, centered card layout. The application includes a fully functional **Java backend** connected to a **MySQL database**, enabling user registration, login authentication, and storing and retrieving user details securely.

## ✨ Features

- 🎨 Red gradient background (top red → bottom dark shade)
- 🧊 Glassmorphism-style card with blur effect
- 📱 Fully responsive, centered layout
- 🔘 Login, Signup, and Display buttons
- ⚡ Smooth hover and focus animations on inputs & buttons

---

## 🛠️ Tech Stack

### Frontend

* **HTML5** – page structure
* **CSS3** – styling, gradients, glassmorphism effects, and animations
* **JSP** – dynamic web pages

### Backend

* **Java** – backend development
* **Java Servlets** – handling login, signup, and requests
* **JDBC** – connecting the Java application with the database

### Database

* **MySQL** – storing and managing user registration and login data

### Development Tools

* **Eclipse IDE** – development environment
* **Apache Tomcat** – web application server
* **Git & GitHub** – version control and project hosting
